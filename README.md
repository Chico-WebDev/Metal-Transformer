## 🌟 Présentation

Metal Transformer est une application dédiée à la **métallerie, soudure et fabrication sur mesure**.
Elle permet de :

* Envoyer des demandes de devis via **WhatsApp et Email**
* Recevoir des confirmations automatiques et stylées
* Gérer les contacts et projets de manière moderne et intuitive

## 📦 Installation

```bash
# Cloner le dépôt
git clone https://github.com/TON_COMPTE/metal-transformer.git

# Installer les dépendances
cd metal-transformer
npm install

# Lancer le projet en mode développement
npm run dev
```
